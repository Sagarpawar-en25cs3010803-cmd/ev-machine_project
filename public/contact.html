Frequently Asked Questions

How is the EV data collected? ▼
Our dataset combines programmatically generated synthetic data (650+ records) based on real-world EV specifications from manufacturer announcements, market reports, and industry databases covering 2020–2026. The data is stored in SQLite and served via JSON.
Can I submit my own EV data? ▼
Yes! Use our Submit EV Data page to add any electric vehicle record. Submissions are stored locally in your browser via localStorage and appear immediately across the platform's listings and dashboard.
Is this data available for academic use? ▼
Absolutely. This project is designed as an academic BI case study. You may reference the visualizations, SQL queries, and analytical methodology for educational and research purposes with proper attribution.
How do the analytics dashboards work? ▼
The React-based executive dashboard (accessible via the main app) uses Recharts for visualizations, with data loaded from JSON. The HTML dashboard page uses Chart.js via CDN. Both read from the same underlying dataset of 650+ EV records.
What battery technologies are covered? ▼
The platform covers five battery chemistries: LFP (Lithium Iron Phosphate), NMC (Nickel Manganese Cobalt), NCA (Nickel Cobalt Aluminum), Sodium-Ion, and Solid-State — each with distinct energy density, cycle life, and safety trade-offs.
How do I run this project locally? ▼
Open public/index.html directly in your browser for the HTML site (no server needed). For the React app, run npm install then npm run dev from the project root, then visit http://localhost:3000.
